# 후속 후보 스펙

0153까지 끝낸 뒤 남은 후속 후보 F1~F9를 운영자가 정한 문장 그대로 한곳에 둔 기준 문서다. 새 결정을 만들지 않는다.

## 1. 운영자 결정(2026-11-21, 후속 후보 그릴링 F1~F9, 모두 추천안 승인)

- F1 Workspace 를 바꾸면 움직임 기억(상태 알약 등)을 비우고 그 뒤 첫 화면은 "처음 그리기"로 봐서 움직이지 않는다. 쌓이기만 하던 끝난 런 기록도 이때 비운다.
- F2 Sheet 가 닫히는 동안 두 번째 클릭(더블클릭의 둘째, event.detail ≥ 2)은 무시하고, 한 번 누른 클릭만 뒤 카드로 보낸다(0153 의 "닫히는 동안 다른 카드 바로 열기"는 유지).
- F3 대기열을 러너별로 세운다: 특정 러너에 고정된 런(이어서 맡기기)은 자기 러너 자리만 기다리고, 다른 런은 비어 있는 러너로 먼저 간다.
- F4 이어서 맡기기로 워크트리를 다시 만들 때도 저장소 설정 스크립트(Orca setup)를 돌린다. 실패하면 그 런은 시작 실패(Failed)로 끝내고 이유를 보인다. 워크트리가 남아 있어 다시 만들지 않으면 돌리지 않는다.
- F5 중복 요청: 화면은 보내는 동안 버튼을 막고, 서버는 같은 요청 ID 를 한 번만 처리한다(0147 방식). 워크트리 지우기·Human Check 답과 런 쓰기 동작(취소, 멈추기, 답하기, 이어서 맡기기)에 같이 적용.
- F6 Funnel 명령: 넘길 주소는 서버가 실제로 받는 주소(loopback·0.0.0.0 → 127.0.0.1, 그 밖은 그 주소). WEB_HOST 가 이 기기의 tailnet 주소면(macOS Tailscale 은 자기 tailnet 주소로 넘기면 멈춘다) 명령 대신 "127.0.0.1 에서도 받게 하세요" 안내. 포트는 `tailscale serve status --json` 을 읽어 443·8443·10000 중 빈 곳, 다 차면 무엇이 쓰는지 보이고 고르게.
- F7 WEB_HOST 가 0.0.0.0(와일드카드)이면 이 기기 자신의 tailnet 주소(IP·MagicDNS 이름, 이 기기 Tailscale 에서 읽음)를 허용 목록에 자동으로 더하고 Settings › 주소에 "자동으로 허용했어요"로 보인다.
- F8 403(주소 허용 안 됨)일 때 데스크톱 앱·웹 모두 꺼지지 않고 안내 화면("이 서버가 {host}를 허용하지 않아요 · 서버 맥에서 Settings › 주소의 다른 기기에서 열 주소에 넣어 주세요"), 데스크톱 앱에는 다른 서버 고르기·다시 시도.
- F9 CI e2e 를 시간 기준으로 나눈다: 파일별 시간 JSON 을 저장소에 두고 Vitest sequencer 가 4개 작업에 고르게 나눈다. 시간 파일은 손으로 가끔 다시 잰다. 목표 가장 긴/짧은 작업 차 1.2배 안.
