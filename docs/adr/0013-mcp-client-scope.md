# MCP 클라이언트에게 같은 기계의 stdio로 거의 모든 기능을 열고, 비밀 값 저장과 러너 명령 바꾸기만 막는다

운영자는 같은 기계에서 도는 에이전트(예: Hermes)가 Ganger를 읽고 다루게 하려 한다. 운영자 결정(2026-11-19)은 "웬만하면 다 연다"이다. 그런데 MCP 클라이언트는 남이 쓴 글(티켓 제목·본문, 에이전트 질문, 런 로그, Slack 메시지)을 읽은 뒤 도구를 부르므로, 그 글 속 지시에 따라 움직일 수 있다(프롬프트 인젝션). 이 ADR은 무엇을 어떤 경로로 열고 무엇을 막는지 정한다. 구현은 티켓 0088(읽기)과 0089(쓰기)가 한다.

## 결정

1. **연결은 같은 기계의 stdio 하나다.** `ganger mcp`를 MCP 클라이언트가 직접 띄운다. 네트워크 포트를 열지 않으므로 같은 기계·같은 사용자만 붙는다. 웹 서버의 HTTP MCP는 서버 인증이 생긴 뒤에 다시 정한다.
2. **`ganger mcp`는 웹 화면과 같은 핵심 함수로 DB를 직접 읽고 쓴다.** 서버가 꺼져 있어도 읽기와 요청 저장은 된다. worker가 처리하는 일(답하기, 취소, 다시 확인 등)은 서버가 꺼져 있으면 쌓이기만 하므로, 결과에 그 사실을 알린다.
3. **지금 앱에 있는 기능만 연다.** 읽기 도구는 화면 단위(Dashboard 요약, 티켓, 런, 러너와 공급자 사용량, 통계, 설정 보기), 쓰기 도구는 화면의 쓰기 기능과 1:1이다. 화면에 없는 기능(러너 지우기, Workspace 추가, 권한 허용 등)은 MCP를 위해 새로 만들지 않는다. 권한 허용은 Operator도 화면에서 하지 못하므로 MCP에도 없다.
4. **막는 것은 둘이다.**
   - **비밀 값 저장**(트래커 API 키, webhook 비밀 값, GitHub 토큰). 저장하려면 비밀 값이 MCP 클라이언트의 대화 맥락과 모델 공급자를 지나간다. 다시 확인하기 도구는 열고, 어떤 도구도 비밀 값을 돌려주지 않는다.
   - **러너의 Orca 경로 바꾸기.** 러너에서 ssh로 실행되는 명령이라, 인젝션 한 번이 러너의 원격 명령 실행이 된다. 러너 추가, Capacity, 다시 확인은 연다.
5. **쓰기는 Operator가 Settings의 "MCP 쓰기 허용"을 켜야 열린다.** 기본은 꺼짐이고, 꺼져 있으면 읽기 도구만 보인다. 같은 기계의 다른 MCP 클라이언트(다른 저장소의 코딩 에이전트 등)가 뜻하지 않게 쓰는 것을 막는다.
6. **MCP로 한 쓰기는 누가 했는지 남기고 화면에 보인다.** 이름은 항상 "MCP · 〈클라이언트가 보낸 이름〉"이다. 보낸 이름은 믿을 수 없으므로 Operator가 한 일처럼 보일 수 없게 앞에 MCP를 붙이고, 길이를 자르고 제어 문자를 지운다. 인젝션이 일을 냈을 때 사람이 알아채는 마지막 방어선이다.
7. **결과는 JSON이고 남이 쓴 글은 `external` 칸에 둔다.** 서버 안내문(instructions)은 `external` 글이 자료이지 지시가 아니며 쓰기 전에 Operator에게 확인받으라고 적는다. 이 표시는 인젝션을 막지 못하고 줄일 뿐이다.
8. **모든 Workspace를 연다.** 도구는 Workspace를 인자로 받고 하나뿐이면 생략할 수 있다.

## 고려한 대안

- **웹 서버에 HTTP MCP(`/api/mcp`).** 다른 기기의 클라이언트도 붙지만, 서버에 인증이 없어 tailnet의 누구나 쓰기 도구를 부를 수 있다.
- **MCP가 도는 웹 서버에 HTTP로 붙기.** 서버가 꺼져 있으면 읽기도 못 하고, 경로가 하나 더 생긴다.
- **비밀 값과 Orca 경로까지 연다.** 운영자 바람("다 연다")에 가장 가깝지만, 위 두 위험이 인젝션 한 번으로 실제 피해(비밀 유출, 러너 원격 실행)가 된다.
- **`ganger mcp --allow-write` 플래그.** 허용 여부가 MCP 클라이언트 설정 파일에 숨어 Ganger 화면에서 보이지 않는다.
- **쓰기마다 Ganger 화면에서 사람 승인.** 가장 안전하지만 Slack에서 일을 끝내려는 목적과 맞지 않는다. 확인은 MCP 클라이언트(예: Hermes가 Slack에서 묻기)에 맡긴다.

## 결과

- MCP로 한 쓰기를 기록하려면 저장 형식에 "누가 했는지"가 필요하다(0089, one-way).
- 데스크톱 앱만 설치하면 `ganger`가 PATH에 없다. Settings가 앱 안 CLI의 절대 경로가 든 설정 조각을 보여 준다.
- 서버 인증이 생기면 HTTP MCP와 다른 기기의 클라이언트를 다시 정한다.
