# 0079 GitHub 저장소 이름을 바꾸기

## 목표

GitHub 저장소 이름을 0076에서 정한 이름으로 바꾸고, 저장소를 가리키는 곳을 맞춘다.

## 범위

- **운영자가 GitHub 설정에서 저장소 이름을 바꾼다.** 에이전트는 바꾸지 않는다.
- 바꾼 뒤 저장소 안의 저장소 주소(README 배지·링크, package.json `repository`, 데스크톱 앱의 업데이트 피드·릴리스 주소, 문서 링크)를 새 주소로 고친다.
- 각 작업 환경의 git remote 주소를 새 주소로 바꾸는 방법을 README 기여 안내나 PR 본문에 적는다. GitHub의 옛 주소 자동 전달에 기대지 않는다.
- PR 본문 스크린숏을 담은 `pr-assets/*` 브랜치 링크가 새 주소에서도 열리는지 확인한다.

## 완료 조건

- 저장소 안에 옛 저장소 주소가 없다(지난 기록 제외).
- 새 주소로 clone·CI·PR 게이트가 돈다.

## 운영자 결정(2026-11-18)

운영자가 저장소 이름 바꾸기를 코디네이터에게 맡겼다. 코디네이터가 `gh repo rename ganger`로 바꿨다. 범위의 "운영자가 바꾼다, 에이전트는 바꾸지 않는다"는 이번에 이 결정으로 대신한다.

## 결과

- 지난 기록(`docs/tickets`의 끝난 티켓, `docs/research`, `docs/adr`) 밖에는 옛 저장소 주소가 든 곳이 없었다. `package.json`에 `repository` 필드가 없고, 데스크톱 앱에 업데이트 피드·릴리스 주소가 아직 없다(0083). 그래서 고칠 주소가 없었고, 소유 계정 이름을 소스에 넣지 않았다.
- README에 Contributing 절을 더해 각 clone의 `origin`을 새 주소로 바꾸는 명령을 적었다(계정 이름은 `<owner>`).
- `pr-assets/*` 브랜치의 PR 본문 스크린숏 링크는 옛 주소(전달)와 새 주소 둘 다 이미지로 열린다.
