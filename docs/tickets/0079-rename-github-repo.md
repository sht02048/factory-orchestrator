# 0079 GitHub 저장소 이름을 바꾸기

## 목표

GitHub 저장소 이름을 0076에서 정한 이름으로 바꾸고, 저장소를 가리키는 곳을 맞춘다.

## 범위

- **운영자가 GitHub 설정에서 저장소 이름을 바꾼다.** 에이전트는 바꾸지 않는다.
- 바꾼 뒤 저장소 안의 저장소 주소(README 배지·링크, package.json `repository`, 데스크톱 앱의 업데이트 피드·릴리스 주소, 문서 링크)를 새 주소로 고친다.
- 각 작업 환경의 git remote 주소를 새 주소로 바꾸는 방법을 README 기여 안내나 PR 본문에 적는다. GitHub의 옛 주소 자동 전달에 기대지 않는다.
- PR 본문 스크린숏을 담은 `pr-assets/*` 브랜치 링크가 새 주소에서도 열리는지 확인한다.

## 완료 조건

- 저장소 안에 옛 저장소 주소가 없다(지난 기록 제외).
- 새 주소로 clone·CI·PR 게이트가 돈다.
