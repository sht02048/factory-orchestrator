# worker 자동 할당과 폴링 보정

## 목표

Auto-assign Label이 붙은 티켓을 사람 없이 할당한다.

## 범위

- 이 티켓은 `apps/worker`만 고친다.
- web이 DB에 기록한 webhook 이벤트를 읽어 할당 조건(core)에 맞으면 db의 할당 진입점(0005)으로 런을 만든다. `Linear-Delivery`로 이미 처리한 이벤트는 건너뛴다. 운영자가 취소한 런의 티켓을 다시 할당할지는 스펙 11절 질문 8의 답을 따른다.
- 폴링 보정: 주기적으로 라벨이 붙은 티켓을 조회해 놓친 할당을 맞춘다(ADR 0001).
- 티켓이 속한 트래커 프로젝트의 Workspace와 Mapping을 찾아 그 러너 쪽 프로젝트·에이전트로 할당 진입점을 부른다. 러너는 할당 진입점이 고른다(Q53).

## 완료 조건

- 같은 webhook 이벤트가 두 번 와도 런이 하나만 생긴다는 테스트가 통과한다.
- webhook을 놓쳐도 폴링 보정으로 런이 생긴다는 테스트가 통과한다.
- 라벨이 붙었지만 Mapping이 없는 트래커 프로젝트의 티켓에는 런이 생기지 않는다는 테스트가 통과한다.
