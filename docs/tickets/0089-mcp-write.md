# 0089 MCP 쓰기: 허용 스위치, 쓰기 도구, 누가 했는지 남기기

## 목표

Operator가 허용하면 MCP 클라이언트가 화면의 쓰기 기능을 쓰게 한다. 결정은 [ADR 0013](../adr/0013-mcp-client-scope.md).

## 범위

- **"MCP 쓰기 허용" 스위치.** Settings MCP 구역, 기본 꺼짐. 꺼져 있으면 `ganger mcp`는 읽기 도구만 보인다. 바꾸면 다시 시작 없이 적용한다.
- **쓰기 도구.** 화면의 쓰기 기능과 1:1에서 막는 것을 뺀다: 티켓 할당, 질문 답하기, 권한 거절, 런 취소, 로그 요청, Workspace 설정(이름·런 최대 시간), 트래커 프로젝트 추가·빼기, Mapping, In progress 상태, Auto-assign Label, 트래커 연결 다시 확인, GitHub 토큰 다시 확인, 이미 있는 러너의 Capacity 바꾸기, 러너 다시 확인, 잠자기. Capacity 도구는 화면의 러너 추가·수정 함수(ssh 대상·Orca 경로·Capacity를 함께 받는다)에 기존 값을 채워 부르지 않고, Capacity만 바꾸는 핵심 함수를 새로 만들어 쓴다. 런 취소처럼 되돌릴 수 없는 도구에는 파괴적 표시(MCP tool annotations)를 단다. 잠자기는 설치 폴더의 파일이라 설치 폴더를 모르면 쓸 수 없다고 알린다.
- **막는 것(도구가 없다).** 비밀 값 저장(트래커 API 키, webhook 비밀 값, GitHub 토큰), 러너 추가와 ssh 대상·Orca 경로 바꾸기(Capacity 도구는 그 둘을 받지 않는다), 주소(다른 기기에서 열 주소, webhook 공개 주소), "MCP 쓰기 허용" 스위치.
- **MCP 작업 기록.** MCP로 한 쓰기를 모두 기록 하나에 남긴다(시각, "MCP · 〈클라이언트 이름〉", 도구, 대상, 결과). 런에 대한 요청(할당, 답하기, 거절, 취소, 로그 요청)은 Run 상세 상태 기록 사이에, 그 밖의 쓰기는 Settings MCP 구역의 최근 작업에 보인다. 클라이언트 이름은 길이를 자르고 제어 문자를 지운다. 저장 형식이 바뀌어 one-way라 사람이 병합한다.
- **서버가 꺼져 있을 때.** worker가 처리하는 쓰기는 결과에 "서버가 켜지면 처리해요"를 알린다.

## 완료 조건

- 스위치가 꺼져 있으면 쓰기 도구가 목록에 없고 불러도 거절된다는 시험.
- 막는 것 넷의 도구가 없고, Capacity 도구가 ssh 대상·Orca 경로를 받지 않는다는 시험.
- MCP 쓰기가 작업 기록에 "MCP · 이름"으로 남고 Run 상세와 Settings MCP 구역에 보인다는 시험(이름에 "Operator"를 보내도 MCP가 붙는다).
- 마이그레이션 시험(기존 DB 올리기).
