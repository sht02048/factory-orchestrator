# CLI: init, start, 서비스 등록

## 목표

운영자가 명령 몇 개로 오케스트레이터를 설정하고 띄우고 상시 서비스로 등록한다.

## 범위

- 이 티켓은 새 앱 `apps/cli`만 만든다(Q56).
- `init`: 부팅 설정(포트, 데이터 경로, 암호화 키, 바인딩 주소)을 만들고 암호화 키를 새로 뽑는다. 이미 있으면 덮어쓰지 않는다.
- `start`: DB 마이그레이션을 실행하고 web과 worker를 띄운다(ADR 0005).
- 서비스 등록: macOS는 launchd, Linux는 systemd 서비스 파일을 만들고 등록·해제한다.
- 운영자 환경 값은 기본값으로 넣지 않는다(ADR 0005).

## 완료 조건

- 임시 폴더에서 `init`을 두 번 돌려도 암호화 키가 바뀌지 않는다는 테스트가 통과한다.
- `start`가 마이그레이션을 실행하고 web이 바인딩 주소에서 응답한다는 테스트가 통과한다.
- launchd plist와 systemd unit 생성 결과가 스냅숏 테스트로 통과한다. 실제 등록은 macOS 한 대와 Linux 한 대에서 확인해 PR에 적는다.
