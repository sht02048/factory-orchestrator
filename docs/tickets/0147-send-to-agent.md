# 0147 에이전트에게 보내기

## 목표

운영자가 Running·Waiting for Input·Paused 런의 Run 상세에서 에이전트에게 말을 보내고, 보낸 말이 타임라인에 남는다. 스펙 [0006](../spec/0006-agent-control.md) C6(운영자 결정 2026-11-21).

## 배경

지금 운영자가 도는 런의 에이전트에게 말할 길은 질문에 답하기와 멈추기·재개뿐이다. "끝내기 전에 push하고 PR까지 열어 줘요"처럼 도중에 고쳐 말하려면 러너 화면으로 가야 한다.

## 할 일

1. Run 상세: Running·Waiting for Input·Paused 런에 "에이전트에게 보내기" 입력칸과 보내기 버튼. 문구는 메시지 파일(ko), 해요체. 보낸 뒤 결과 문장은 `role="status"`, 포커스는 입력칸 ref로 되돌린다.
2. web은 보내기 요청을 DB에 적고(run별 요청 표, 0118의 run_control_requests와 같은 모양), worker가 러너 어댑터로 Orca `orchestration send --to dispatch:<id>`를 부른다. 출력은 zod로 파싱하고 러너 호출 로그 규칙을 따른다.
3. 런 타임라인에 "운영자가 보냄"과 보낸 말을 남긴다. 보내지 못하면 이유를 Run 상세에 보인다.
4. 여러 런에 한꺼번에 보내지 않는다. MCP 쓰기 도구는 더하지 않는다.

## 열린 질문

- Paused 런에 보낸 말이 런을 재개하는지.
- Waiting for Input 런에 보낸 말을 질문의 답으로 다루는지.

답 전에는 정하지 않고 코디네이터에게 묻는다.

## 완료 조건

- 시험: 상태별 입력칸 보이기·숨기기, 요청 저장과 worker 보내기, 실패 이유, 타임라인, 400px.
- 스크린숏: Run 상세 입력칸, 타임라인의 "운영자가 보냄".
- 화면 변경 있음. DB 변경 있음(요청 표, one-way).
