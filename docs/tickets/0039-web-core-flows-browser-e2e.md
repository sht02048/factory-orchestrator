# 핵심 흐름 브라우저 e2e

## 목표

운영자가 가장 자주 누르는 동작이 실제 브라우저에서 끝까지 도는지 CI에서 확인한다. 운영자 결정(2026-11-18)으로 0029 앞에 둔다.

## 범위

- 운영자의 핵심 동작 2~3개를 실제 브라우저로 누르는 시험을 만든다: 에이전트 질문에 답하기, 런 취소, 수동 할당.
- 어댑터는 목 어댑터를 쓰고 DB는 시험마다 임시로 만든다. 운영자 환경이나 계정이 필요하지 않다.
- 시드가 필요하면 Settings(0025)의 저장 경로나 db 함수를 쓴다. 화면 코드는 시험을 위해 바꾸지 않는다.
- CI `check`에 이 시험을 더하고 `AGENTS.md`의 CI 목록을 함께 맞춘다.

## 완료 조건

- 브라우저로 질문에 답하면 그 답이 DB에 남고 화면에 보인다는 시험이 통과한다.
- 브라우저로 런을 취소하면 취소 요청이 DB에 남고 화면에 "취소 중"이 보인다는 시험이 통과한다.
- 브라우저로 티켓을 수동 할당하면 Queued 런이 생기고 Runs 화면에 보인다는 시험이 통과한다.
- 위 시험이 CI `check`에서 돈다.
