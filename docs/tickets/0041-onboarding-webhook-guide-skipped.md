# 온보딩 트래커 단계의 webhook 안내가 건너뛰어짐

## 목표

운영자가 온보딩에서 Linear webhook을 만들고 signing secret을 넣은 뒤에 다음 단계로 가게 한다.

## 배경

완료 기준 시험(research [0011](../research/0011-acceptance-run.md))에서 첫 진입 주소 `/onboarding`(단계 없음)으로 트래커 연결을 저장하자 화면이 바로 2단계로 넘어갔다. 저장 뒤 다시 읽을 때 주소에 단계가 없어 `resolveStep`이 끝나지 않은 첫 단계(2단계)를 고르기 때문이다. webhook 경로(`/api/webhooks/tracker/<연결 ID>`)와 "Linear에서 webhook 만들기" 안내는 연결을 저장한 뒤에만 1단계에 보이므로, 운영자는 이전으로 돌아가지 않으면 이 안내를 보지 못한다. webhook 없이 온보딩을 끝내면 자동 할당은 5분 폴링 보정으로만 일어난다(ADR 0001).

## 범위

- 이 티켓은 `apps/web`의 온보딩 라우트와 화면만 고친다.
- 트래커 연결을 저장한 뒤에는 1단계에 머물러 webhook 경로와 안내를 보인다. 다음으로 가는 것은 운영자가 "다음"을 눌러서다.
- signing secret은 webhook을 만든 뒤에야 받으므로, 연결을 추가할 때는 비워 둘 수 있고 저장한 뒤 넣는다는 순서를 안내에 맞춘다. 비워 두고 다음으로 가면 webhook이 서명 검증에 실패한다는 것을 알린다(막지는 않는다. 폴링 보정으로도 돈다).

## 완료 조건

- 단계 없는 주소로 들어와 트래커 연결을 저장하면 1단계에 머물고 webhook 경로가 보인다는 테스트가 통과한다.
- signing secret 없이 저장한 연결이면 1단계에 그 사실이 보인다는 테스트가 통과한다.
