# 0063 런에 티켓 제목, 러너에 Offline 시각 저장

## 목표

Dashboard 행과 Runners 카드가 시안대로 보이게, 화면이 읽을 데이터를 저장한다.

## 배경

0060에서 두 가지를 데이터가 없어 줄였다.

- 런에는 티켓 제목이 저장되지 않는다. 제목은 Tickets 화면만 트래커에서 그때그때 읽는다. 그래서 Dashboard 행의 제목 자리에 티켓 키를 Run 상세 링크로 둔다. ADR 0010 9번은 티켓을 어디서나 "회색 키 + 제목"으로 보이라고 한다.
- 러너가 Offline이 된 시각이 없다. 그래서 Runners 카드가 "Offline · {경과}째" 대신 "Offline"만 보인다.

## 범위

- 할당할 때 트래커에서 읽은 티켓 제목을 런에 저장한다(DB 마이그레이션). 제목이 나중에 트래커에서 바뀌면 어떻게 할지(할당 시점 값 유지 또는 webhook으로 갱신)를 정하고, 되돌리기 어려운 저장 형식 결정이면 ADR로 남긴다.
- 러너 상태가 Online에서 Offline으로 바뀐 시각을 저장한다.
- Dashboard, Runs, Run 상세의 행이 키 옆에 제목을 보이게 하고, Runners 카드가 Offline 경과를 보이게 한다.

## 완료 조건

- 마이그레이션 시험(기존 DB 올리기 포함).
- 할당한 런의 제목이 저장되고 Dashboard 행에 보인다는 시험.
- Offline 경과가 보인다는 시험.
- PR 머지 위험은 one-way(저장 형식 변경)라 사람이 직접 병합한다(AGENTS.md).
