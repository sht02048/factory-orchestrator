# core 어댑터 인터페이스를 검증 결과에 맞추기

## 목표

검증 티켓(0009~0012)의 결과로 `Tracker`·`Runner`·`CodeHost` 인터페이스와 가짜 어댑터를 한 번에 고친다. 어댑터 티켓(0013~0015)이 `packages/core`를 고치지 않고 함께 돌 수 있게 하려는 것이다.

## 범위

- 이 티켓은 `packages/core`와, 인터페이스가 바뀌면 그것을 부르는 `apps/worker`·`e2e/` 코드만 고친다. 0006·0008 뒤, 0016 앞에 둬서 그동안 `apps/worker`를 고치는 다른 티켓이 없게 한다.
- 0009~0012 research 문서에 맞춰 인터페이스 타입, 외부 열거값, 오류 종류를 고친다(에이전트 멈추기 방법, 종료 코드, 입력 기다림 신호, webhook 이벤트 분류, 티켓 키로 PR 찾기 등).
- 가짜 어댑터를 같은 인터페이스에 맞춘다. 바뀐 점은 PR에 적는다.
- 고칠 것이 없으면 그 근거를 PR에 적고 문서만 바꾼다.

## 완료 조건

- core·worker·e2e의 기존 테스트와 저장소 전체 typecheck가 통과한다.
- 0009~0012에서 확인한 사실 중 인터페이스에 닿는 것마다 반영 여부가 PR에 적혀 있다.
