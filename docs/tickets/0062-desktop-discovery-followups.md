# 0062 데스크톱 앱 서버 찾기 후속

## 목표

데스크톱 앱 화면 개편(#89)의 독립 리뷰가 남긴 막지 않는 지적을 마저 고친다.

## 범위

- **https 주소로도 찾기.** 서버 찾기는 기기마다 http 주소가 `host-not-allowed`로 답하고 IPv4로 다시 물어도 열 수 없으면 거기서 멈춘다(`src/core/discovery.ts`의 `probeDevice`). 바인드 주소가 `0.0.0.0`이고 다른 기기에서 열 주소가 Tailscale Serve의 https 주소인 서버는 https로 물으면 열 수 있다. 모든 주소를 물은 뒤에 "열 수 없어요"로 정한다.
- **IPv4 검증.** `TailscaleIPs`의 IPv4를 정규식이 아니라 `z.ipv4()`나 `net.isIPv4`로 거르고, `URL`에 넣은 뒤 호스트 이름이 그대로인지 확인한다. `999.1.1.1`은 무시되고 `010.064.000.002`는 8진수로 읽혀 다른 주소가 된다.
- **상태 색.** "이 이름으로는 열 수 없어요" 안내와 닿지 않음 화면의 "계속 다시 확인하고 있어요." 옆 점(`styles.liveDot`)이 Human Check의 노랑(`colors.check`)을 쓴다. 상태 색은 그 뜻을 그릴 때만 쓴다(`packages/ui/DESIGN.md`). 보조 글자색이나 새 의미 토큰으로 바꾼다.
- **로그 파일이 없을 때.** 서버가 로그를 쓰기 전에 실패하면 "로그 열기"가 아무것도 하지 않는다(`shell.showItemInFolder`는 없는 파일에 아무것도 하지 않는다). 로그 폴더를 연다.
- **아이콘 버튼 이름.** 서버 찾기의 "다시 찾기" 아이콘 버튼을 `Tooltip`으로 감싸 보이는 이름을 준다.
- **화면이 바뀔 때 포커스.** 누른 버튼이 사라지는 화면 전환(서버 찾기, 서버 켜기 등)에서 포커스가 `body`로 떨어진다. 새 화면의 제목으로 옮긴다.
- **문구.** "tailnet 에서"·"Tailscale 을"의 띄어쓰기를 다른 문구와 맞추고, "이 맥"을 "이 기계"로 맞춘다.

## 범위 밖

- `packages/ui` `Button`에 크기 옵션 더하기와 데스크톱 앱 화면 렌더 시험. 데스크톱 앱 화면은 지금 `buttonStyles`에 높이만 덮어 큰 버튼을 만든다.

- `pnpm typecheck`, `pnpm lint`, `pnpm run check:colors`, `pnpm format:check`, `pnpm test`가 통과한다.
