# 끝에서 끝까지 얇은 경로 시험

## 목표

가짜 어댑터로 할당 → 런 → 판정 → 화면 표시가 실제로 이어진다는 것을 자동 시험 하나로 증명한다. 이후 티켓이 이 경로를 깨면 CI가 막는다.

## 범위

- 이 티켓은 루트 `e2e/` 폴더와 그 시험을 CI에서 돌리는 설정만 더한다. 앱 코드는 고치지 않는다.
- 임시 DB로 web과 worker(가짜 어댑터 주입)를 띄우고, 할당 진입점으로 런을 만든 뒤 worker가 판정할 때까지 기다리고, Runs 화면에서 그 결과를 읽는다.
- 결과 셋(Merged, Human Check, Failed)을 각각 한 번씩 돌린다.

## 완료 조건

- `pnpm test`(또는 CI `check`)에서 세 시나리오가 통과한다.
- 판정 함수의 결과를 일부러 바꾸면 이 시험이 실패한다는 것을 확인했다(커밋하지 않음).
