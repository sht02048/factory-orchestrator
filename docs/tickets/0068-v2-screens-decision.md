# 0068 화면 개편 v2 결정(Dashboard·Tickets·Runners·Stats)

## 목표

구현된 화면을 운영자가 리뷰하고 고른 개편안(2026-11-18)을 ADR과 GLOSSARY에 먼저 적는다. 화면 구현은 0069~0072가 한다.

## 배경

운영자가 `pnpm dev`로 본 화면에서 짚은 문제다.

- Dashboard: 카드 네 개가 같은 모양이고 제목이 작아 무엇이 무엇인지 모른다. To do가 진한 알약 11줄이고 Failed 일곱 줄이 같은 문장을 되풀이한다.
- Tickets: 필터 이름(전체·손댈 일·할당 전·Running·Merged)이 한국어·영어가 섞이고 기준이 섞였다. 같은 값만 되풀이하는 열(트래커 프로젝트, 트래커 상태)이 있다. 페이지가 통째로 스크롤돼 머리와 필터가 사라진다.
- Runners: 카드 한 장에 capacity, 런, 확인 항목, 해결 안내, 남은 워크트리가 다 들어가 높이가 제각각이고, 상태 알약이 두 개씩 붙는다.
- Stats: 숫자 칸 다섯 개가 4+1로 끊기고, 결론 문장이 없고, 실패 이유가 내부 조합 이름이고, 늘 붙은 오른쪽 패널이 화면을 좁힌다.

## 범위

ADR 0010에 갱신 단락을 더한다(0059가 쓴 방식을 따른다).

1. **화면 제목(8번).** Dashboard와 Stats는 결론 문장을 제목으로 쓰고, 화면 이름은 그 위의 작은 메타 줄에 둔다. 다른 화면은 지금 규칙(화면 이름 + 요약 한 줄)을 따른다.
2. **Dashboard.** To do를 하는 일로 묶는다: 답이 필요해요(Question, Permission), 확인해 주세요(Human Check), 멈췄어요(Failed, Disconnected). 묶음 머리의 색 점과 이름이 행마다의 상태 알약을 대신한다(ADR 0010 4번 "상태는 알약"의 예외로 적는다). 되풀이되는 설명은 묶음 머리에 한 번만 둔다. To do만 면이 있는 카드이고, In progress와 오른쪽 열(Runners, Done today)은 면 없이 제목과 목록만 둔다.
3. **Runners.** 러너 카드를 목록 + 오른쪽 상세 패널(ADR 0007)로 바꾼다. 행에는 상태 하나만 보인다(Runner Issue와 Offline이 Online보다 앞선다).
4. **Tickets 필터.** 모두 / 할당할 수 있음 / 처리할 일 / 진행 중 / 끝남. 키·제목 검색을 둔다. 화면 머리·필터·열 이름은 고정하고 목록만 스크롤한다.
5. **Stats.** 오른쪽 상세 패널을 없앤다. 기간(7일·14일·30일)을 고르고 앞 기간과 비교한다. 실패 이유는 에이전트 결과·PR 상태 조합 이름 대신 말로 쓴다.

GLOSSARY에 Tickets 필터 낱말(할당할 수 있음, 진행 중, 끝남)을 정의하고, 같은 뜻의 옛 낱말을 _Avoid_에 둔다.

## 범위 밖

코드, 메시지 파일, 시험은 고치지 않는다(0069~0072).

## 완료 조건

- ADR 0010과 GLOSSARY가 위 결정을 담고, 서로 어긋나는 문장이 없다.
- 티켓 0066(Dashboard 다듬기)은 0069에 합쳐 status를 done으로 두고 첫 줄에 "0069에 합쳤다"를 적는다. 티켓 0067의 Stats 묶음 표 부분은 0072로 옮겼다고 적는다(Button 부분은 0067에 남긴다).
