# 0071 Runners v2

## 목표

0068의 Runners 결정(카드 → 목록 + 상세 패널)을 구현한다.

## 화면

- 머리: "Runners", 요약(예: "3대 중 2대에 문제가 있어요. 지금 새 런을 받을 수 있는 러너가 없어요."), 오른쪽에 "러너 추가"(주 버튼).
- 목록: 문제 있는 러너가 위. 행은 상태 알약 하나(Runner Issue / Offline / Online) · 이름 · 주소(말줄임) · capacity 막대와 "1/2", 그 아래 한 문장(무엇이 문제인지, 또는 "꽉 찼어요. 런 {n}개가 자리를 기다려요.").
- 상세 패널(고른 러너): 상태 · 확인 시각, 이름 20px, 주소(모노, 줄바꿈). 문제가 있으면 맨 위에 해결 상자(제목, 번호 단계, "다시 확인" 버튼). 그다음 "지금 하는 런 · {n}/{capacity}", "확인 항목 · {통과}/{전체} 통과"(실패 먼저), 남은 워크트리.
- Dashboard·Home에서 `sel`로 들어오면 그 러너를 고르고 포커스한다(0057 동작 유지).

## 완료 조건
