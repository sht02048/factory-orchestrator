# 0149 이어서 맡기기

## 목표

워크트리가 남은 끝난 런에서 같은 러너·워크트리·브랜치로 새 런을 시작해 남은 일을 이어 맡긴다. 스펙 [0006](../spec/0006-agent-control.md) C5(운영자 결정 2026-11-21).

## 배경

0145(R7)부터 남은 일이 있는 워크트리는 지우지 않고 남긴다. 남긴 워크트리를 이어 일하게 하려면 지금은 러너에서 직접 에이전트를 띄워야 한다. 같은 티켓에 새로 할당하면 새 워크트리에서 처음부터 시작한다.

## 할 일

1. Run 상세: 워크트리가 남은 끝난 런에 "이어서 맡기기"를 둔다. 대화상자에 이어 받는 곳(러너, 같은 워크트리와 브랜치), 새 런 번호("런 #n을 이어서"), 에이전트에게 할 말, 함께 보내는 것(이전 런 완료 보고, Workspace 앞뒤 지시, 통신 규약)을 보인다.
2. 새 런을 같은 러너·워크트리·브랜치로 시작한다. 두 런을 잇는 기록(DB)을 두고 Run 상세·타임라인에 "런 #n을 이어서"로 보인다.
3. 지시서: 운영자의 말 + 이전 런 보고 + 앞뒤 지시 + 통신 규약. 0146의 `packages/core/src/agent-brief.ts`를 넓혀 같은 곳에서 합친다. 받은 지시서는 0146처럼 런에 저장한다.
4. 워크트리가 지워졌으면 같은 브랜치로 새 워크트리를 만든다. 브랜치도 없으면 처음부터 시작한다. 어느 경우인지 Run 상세에 보인다.
5. 러너 쪽 명령은 Orca 러너 어댑터 경로를 넓히고 출력은 zod로 파싱한다. MCP 쓰기 도구는 더하지 않는다.

## 완료 조건

- 시험: 같은 워크트리로 시작, 워크트리 없음·브랜치 없음, 지시서 순서, 두 런 잇기, 대기열·capacity, 400px.
- 스크린숏: 이어서 맡기기 대화상자, 이어 받은 런의 Run 상세.
- 화면 변경 있음. DB 변경 있음(런 잇기, one-way).
