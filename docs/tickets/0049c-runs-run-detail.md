# 0049c Runs + Run 상세

묶음 티켓 [0049](0049-ui-redesign.md)의 하위 티켓이다. [0049a](0049a-ui-base.md)의 토큰·`StatusPill`·`Card`·`Row`·`useTime()`을 쓴다.

## 범위

- **Runs.** 상태 칩 필터 + 둥근 행(회색 키 + 제목, 러너·에이전트 흐린 줄, 알약, 경과 또는 상대 시간). 목록 + 상세 패널은 그대로(ADR 0007). 끝난 런의 시간 칸은 상대 시간("53분 전")으로 바꾼다. 지금은 걸린 시간을 쓴다.
- **Run 상세.** 전체 화면. 질문 카드를 맨 위에(선택지는 모두 보조 버튼), 그 아래 타임라인(시각 "10:45"), 오른쪽 정보 카드와 터미널 끝부분. 런 취소는 위험 보조 버튼.

## 완료 조건

- Run 상세에 파란 주 버튼이 하나 이하이고 질문 선택지가 모두 보조 버튼이라는 시험.
- Runs·Run 상세의 상태 알약 글이 영어 용어 안에 있다는 시험.
- `pnpm dev`로 띄운 Runs·Run 상세 스크린숏을 PR에 붙인다.
