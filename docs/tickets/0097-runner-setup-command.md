# 0097 러너 등록 간소화 2: 다른 맥 · 명령으로 등록

## 목표

다른 맥을 러너로 등록할 때 그 맥 터미널에 명령 한 줄을 붙여 넣어 끝낸다. 0095의 고르기 화면에서 "다른 맥 · 터미널 명령으로"를 고르면 이 흐름으로 간다.

## 운영자 결정(2026-11-19, 시안 U10·U11)

- 필요한 것: 그 맥에 Orca 앱, 같은 tailnet, 이 서버의 다른 기기용 주소.
- 명령은 10분 동안 한 번만 쓸 수 있다.
- 명령이 하는 일은 0095의 "이 맥을 러너로"와 같다: Ganger 공개 키 등록, 호스트 키 고정, Orca 상시 서비스 설치, GitHub 인증 정리, 러너 등록. 원격 로그인 켜기만 사람이 한다.

## 범위

- 0095가 만든 Ganger 전용 ssh 키와 관리 방식(`access`)을 그대로 쓴다.
- 0095에서 "곧 지원"으로 둔 선택지를 연다.

## 완료 조건

- 한 번 쓴 명령과 10분이 지난 명령이 거절되는지 시험한다.
- 명령이 등록한 러너가 Ganger 관리 러너로 저장되고 확인을 통과하는지 시험한다.
