# web Run 상세 화면

## 목표

런 하나의 결과와 이유, 타임라인, PR·CI, 로그 꼬리를 본다.

## 범위

- 이 티켓은 `apps/web`의 Run 상세 라우트와 그 화면 메시지만 고친다.
- 에이전트 결과와 PR 상태 두 칸, 그로부터 계산한 요약 결과(core 요약 계산 함수, Q66), 다음 행동, 타임라인(할당·시작·입력 기다림·연결 끊김·다시 연결·종료, Q67), 대기 시간과 실행 시간(Q59), PR·CI 상태(worker가 DB에 쓴 값, 0017), 이후 PR 상태(Q54·Q69).
- Disconnected 런은 "연결 끊김"과 ssh가 실패하기 시작한 시각을 보인다. 에이전트 결과가 러너 연결 끊김이고 워크트리를 아직 지우지 않았으면 "사람이 지워야 함"을 보인다. 지우기 버튼은 두지 않는다(Q75).
- 취소: Queued와 Running 런에 취소 행동을 둔다. 누르면 DB에 취소 요청을 남기고 worker가 처리한다(Q61·Q77).
- 로그 꼬리: 화면을 열면 DB에 로그 꼬리 요청을 남기고, worker가 쓴 결과를 읽어 보인다. web은 ssh를 쓰지 않는다(Q61). Ended 런은 저장한 마지막 200줄을 보인다(Q46).
- 오른쪽에 런 속성과 같은 티켓의 다른 런(시안 B).

## 완료 조건

- core가 가진 에이전트 결과 전부(0037 뒤에는 운영자가 취소함을 더한 일곱)와 PR 상태 넷이 각각 맞는 문구로, 요약 결과가 요약 계산 표대로 보인다는 테스트가 통과한다.
- Disconnected 런과 워크트리를 지우지 않은 러너 연결 끊김 런이 각각 "연결 끊김", "사람이 지워야 함"으로 보인다는 테스트가 통과한다.
- 화면을 열면 로그 꼬리 요청이 DB에 하나 생기고, DB에 결과를 넣으면 화면에 보인다는 테스트가 통과한다.
- Queued·Running 런에서만 취소 행동이 보이고, 누르면 취소 요청이 DB에 하나 생긴다는 테스트가 통과한다.
- web 코드에 ssh 호출이 없다.
