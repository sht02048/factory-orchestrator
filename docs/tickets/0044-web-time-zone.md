# 화면 시각을 운영자 시간대로 보이기

## 목표

화면의 시각과 날짜를 운영자의 시간대로 보인다.

## 배경

`apps/web/src/i18n.tsx`가 `timeZone = "UTC"`로 고정해 모든 시각과 날짜를 UTC로 보인다. 표시에 시간대가 없어 운영자는 UTC인 줄 모른다. 완료 기준 시험(research [0011](../research/0011-acceptance-run.md))에서 UTC+9 환경의 2026-11-18 02:44에 러너 확인 시각이 "2026. 11. 17. 오후 5:44에 확인했어요"로, Run 상세 타임라인이 "11. 17. 17:46"으로, Stats 기간 끝이 "11월 17일"로 보였다. 서버 렌더링과 브라우저가 같은 값을 그리게 하려고 고정한 것으로 보인다.

## 범위

- 이 티켓은 `apps/web`의 i18n 설정과 시각을 그리는 곳만 고친다.
- 시간대를 어디서 정할지(설치 설정, 브라우저 시간대) 정한다. 서버 렌더링과 브라우저의 hydration이 어긋나지 않아야 한다.
- Stats의 날짜 구간(최근 14일, 날짜별 처리량)도 같은 시간대로 자른다.

## 완료 조건

- 다른 시간대에서 같은 런의 타임라인 시각이 그 시간대로 보인다는 테스트가 통과한다.
- 날짜 경계를 넘는 런이 그 시간대의 날짜로 Stats에 묶인다는 테스트가 통과한다.
