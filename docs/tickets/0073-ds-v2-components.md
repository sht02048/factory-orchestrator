# 0073 디자인 시스템 v2: 글자·면 역할과 새 컴포넌트

## 목표

화면 개편 v2(0068~0072)가 쓸 글자 역할, 면 역할, 공용 컴포넌트를 `packages/ui`에 먼저 만든다. 화면은 이것을 가져다 쓰기만 한다.

## 배경

2026-11-18 기준 `apps/web/src`(시험 제외)를 세면 화면이 디자인 시스템을 우회한다. `Text` 변형은 125번 쓰지만 `fontSize.*` 토큰을 직접 쓴 곳이 56곳, `fontWeight.*` 30곳이다. 토큰을 직접 가져오는 import가 colors 11, space 11, fontSize 9, fontWeight 7, radius 4, lineHeight 3이다. 스타일에 px 숫자가 115곳 있다. 구역 제목 역할 `section`이 14px라 본문과 같아 Dashboard 구역 제목이 안 보였고, 결론 제목(26px)·구역 제목(20px)을 넣을 단계가 없다.

## 범위

- **글자 역할**: 역할마다 크기·굵기·줄 높이·자간을 한 묶음으로 정한다. 기존 변형(page 22, panel 17, section 14, title, body, ui, meta, label)의 값은 바꾸지 않는다(지금 화면이 깨지지 않게). 새 역할을 더한다: `display`(26/600, 결론 제목), `heading`(20/600, 주 구역 제목), `subheading`(15/600, 보조 구역·카드 제목). 이름은 저장소 관례에 맞게 정해도 된다. 기존 `section`(14)은 0074에서 정리한다.
- **글자 함수**: `Text`를 쓸 수 없는 요소(제목 태그, 버튼 안 글자 등)를 위해 역할 이름으로 스타일을 돌려주는 함수(예: `textStyles(role)`)를 `packages/ui`에서 내보낸다.
- **면 역할**: `surface(role)` 또는 `Card` 변형으로 정한다. 주 구역 카드(면 있음), 면 없는 구역, 안쪽 상자(inset), 문제 상자(problem). 둥글기·안쪽 여백을 역할에 묶는다.
- **새 컴포넌트**(각각 `/ds` 미리보기와 시험):
  - `SegmentedTabs`: 한 줄 묶음 탭, 항목마다 개수, `role="tablist"`, 키보드 이동. Tickets 필터, Stats 기간·나눠 보기가 쓴다.
  - `GroupHeader`: 색 점 + 이름 + 개수 + 오른쪽 설명. 색은 상태 색 토큰. Dashboard To do 묶음이 쓴다.
  - `CapacityBar`: 쓰는 칸/전체 칸 막대와 "1/2" 글, 톤(진행·문제). Dashboard Runners, Runners 목록이 쓴다.
  - `ProblemCallout`: 제목, 번호 단계(선택), 행동 버튼(선택). Dashboard 러너 문제, Runners 해결 상자가 쓴다.
  - `StatTile`: 큰 숫자, 뜻, 보조 줄(비교는 오름·내림 색). Stats가 쓴다.
  - `Section`: 제목 역할(heading/subheading) + 개수 + 오른쪽 링크. 기존 `Section`이 있으면 넓힌다.
- **`/ds` 페이지**: 새 역할과 컴포넌트를 모두 미리보기로 보인다.
- **`DESIGN.md`**: 글자 역할 표, 면 역할 표, 새 컴포넌트마다 "언제 쓰는지 / 쓰지 않는지"를 적는다. 화면은 역할과 컴포넌트만 쓰고 토큰을 직접 쓰지 않는다는 방향을 적는다(강제는 0074).

## 범위 밖

화면(`apps/web/src` 중 `ds/` 밖)은 고치지 않는다. 화면을 새 역할로 옮기는 일은 0069~0072와 0074가 한다.

## 완료 조건

- 새 컴포넌트마다 단위 시험(역할·키보드·접근성 이름)과 `/ds` 미리보기.
- `/ds` 1280px 스크린숏을 PR에 붙인다.
- 기존 화면 시험이 그대로 통과한다(기존 변형 값을 바꾸지 않았다는 근거).
