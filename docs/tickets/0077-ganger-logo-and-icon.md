# 0077 Ganger 로고와 앱 아이콘

## 목표

Ganger 로고와 데스크톱 앱 아이콘을 만든다.

## 범위

- 로고 시안을 몇 가지 만들어 운영자가 고른다(다크 톤, ADR 0010의 둥근 면 규칙과 어울리게). 다른 회사·제품 로고를 흉내 내지 않는다.
- 고른 안으로 만든다:
  - macOS 앱 아이콘(`.icns`, 크기별 그림)과 dmg 볼륨 아이콘.
  - 레일 맨 위 로고(지금 Workspace 글자 칸 자리와의 관계를 정한다).
  - 웹 파비콘과 문서 제목 옆 아이콘.
  - README 머리 로고(밝은·어두운 바탕).
- 원본 파일(SVG)을 저장소에 둔다. 글꼴을 쓴다면 라이선스를 확인한다.

## 완료 조건

- 아이콘이 `pnpm dev` 화면과 패키징한 앱(.app)에 보인다는 스크린숏을 PR에 붙인다.
