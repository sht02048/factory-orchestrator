# 0072 Stats v2

## 목표

0068의 Stats 결정을 구현한다. 티켓 0067의 Stats 묶음 표 부분도 여기서 끝난다.

## 화면

- 메타 줄 "Stats · {Workspace} · {기간}", 제목(26px) "끝난 런 {n}개 중 {r}%를 에이전트가 병합까지 끝냈어요", 오른쪽에 기간 7일 · 14일 · 30일.
- 숫자 넷(같은 모양 카드): 병합률(앞 기간 대비 "{d}%p 올랐어요/내렸어요"), 사람이 손댄 비율(Human Check · Failed 개수), 리드 타임 중앙값("느린 10%는 {p90} 넘게"), 끝난 런("Canceled {n}은 비율에서 빼요").
- 날짜별로 끝난 런: 전체 폭 쌓인 막대, 범례는 제목 옆, 마지막 날은 "오늘", "표로 보기" 유지(0053).
- 왜 실패했나요 {n}: 실패 이유를 말로(예: 에이전트가 실패를 보고했어요 / 에이전트가 중간에 멈췄어요 / 최대 실행 시간을 넘겼어요)와 막대·개수. PR 상태는 한 줄 설명으로.
- 나눠 보기: 러너 · 트래커 프로젝트 · 에이전트 탭, 열은 이름 · 런 · 결과(색 막대 하나) · 리드 타임. 행을 누르면 그 조건으로 Runs를 연다(0075 로 옮김. Runs가 이 조건을 받지 않아 이 티켓에서는 누를 수 없는 표로 둔다).
- 오른쪽 상세 패널은 없다.

## 범위

기간 선택과 앞 기간 비교 계산을 Stats 로더에 더한다.

## 완료 조건

- 기간을 바꾸면 숫자·차트가 바뀐다는 시험, 앞 기간 비교 시험, 실패 이유 문구 시험.
- 1280px 스크린숏을 PR에 붙인다.
