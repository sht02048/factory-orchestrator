# 0107 모바일 4: 앱에서 답하기·거절·취소

## 목표

앱에서 Question에 답하고, Permission을 거절하고, 런을 취소한다. 답을 보내면 그 런이 다시 Running이 된다(스펙 [0002](../spec/0002-mobile.md) 1절 둘째 완료 기준, M3).

## 범위

- v1 쓰기 계약: 답하기, Permission 거절, 런 취소. 지금 서버 함수와 같은 규칙을 쓴다.
- 이 화면들이 읽는 v1 계약: 답하기 시트의 질문과 선택지, "로그 보기"의 런 로그.
- 답하기 시트: 질문, 맥락 한 줄, 선택지와 설명, "직접 쓰기", 아래에 고정한 "보내면 되돌릴 수 없어요"와 "보내기". 고르기만 해서는 보내지 않는다(ADR 0010 6번).
- Permission 카드의 "거절"과 "허용은 러너의 Orca에서 해요" 안내(ADR 0009).
- Queued·Running 카드 메뉴의 "Linear에서 열기"와 "런 취소". 취소는 확인 시트를 거친다.
- Failed·Disconnected 카드의 "로그 보기".

## 시작할 때 운영자와 정할 것

- "로그 보기"가 웹 Run 상세의 어디까지 보일지(스펙 0002 열린 질문 8).

## 범위 밖

- 할당과 Failed 다시 맡기기(0111).

## 완료 조건

- v1 쓰기 계약으로 답을 보내 런이 Running으로 돌아가는 e2e 시험(가짜 어댑터)과, 앱 답하기 시트의 컴포넌트 시험이 있다. 앱 전체를 도는 e2e 도구는 이 티켓에서 정하지 않는다.
- 거절과 취소가 서버에 반영되는 시험이 있다. 이미 다른 상태가 된 런에 늦게 간 쓰기는 거절되고 앱이 그 이유를 보인다.
