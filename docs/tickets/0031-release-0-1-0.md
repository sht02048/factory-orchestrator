# 0.1.0 릴리스

## 목표

1단계를 npm에 0.1.0으로 공개한다.

## 범위

- Changesets로 0.1.0 버전과 변경 기록을 만들고 npm에 publish한다(ADR 0005).
- publish를 어디서 할지(로컬 또는 GitHub Actions)는 이 티켓에서 정한다. 토큰은 저장소에 넣지 않는다(ADR 0005).
- 운영자 준비가 필요하다: npm 계정과 publish 토큰, 패키지 이름이 비어 있는지 확인.

## 완료 조건

- npm에서 0.1.0을 설치해 `init`·`start`가 돈다.
- GitHub에 `v0.1.0` 태그와 변경 기록이 있다.
