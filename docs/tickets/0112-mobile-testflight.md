# 0112 모바일 9: TestFlight 배포

## 목표

iOS 앱을 데스크톱 앱과 같은 Apple 개발자 팀으로 서명해 TestFlight 외부 테스트로 배포한다. 심사관은 앱 안 데모 모드로 모든 화면을 본다(스펙 [0002](../spec/0002-mobile.md) 9절, M7).

## 범위

- iOS 서명 자격 증명과 빌드·제출 방법. 서명 값, 팀 ID, 키는 저장소에 두지 않는다.
- 심사용 데모 모드 진입과 심사 메모.
- 배포 절차 문서(영어, 사용자 문서).
- 배포는 운영자가 말할 때만 한다.

## 완료 조건

- 운영자가 말한 때에 TestFlight 빌드가 올라가고, 데모 모드로 심사를 통과한다.
