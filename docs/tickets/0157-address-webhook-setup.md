# 0157 주소와 webhook 설정

## 목표

Tailscale Funnel 명령이 이 서버의 실제 바인드 주소와 비어 있는 포트를 쓰게 하고, 와일드카드로 띄운 서버가 이 기기의 tailnet 주소를 스스로 허용하게 하며, 주소가 허용되지 않았을 때 웹과 데스크톱 앱이 다음 할 일을 보이게 한다.

## 운영자 결정(2026-11-21, 후속 후보 그릴링)

- **F6 Funnel 명령.** 넘길 주소는 서버가 실제로 받는 주소다(loopback·`0.0.0.0` → `127.0.0.1`, 그 밖은 그 주소). `WEB_HOST`가 이 기기의 tailnet 주소면 macOS Tailscale이 자기 tailnet 주소로 넘길 때 멈추므로, 명령 대신 "127.0.0.1에서도 받게 하세요"를 안내한다. 포트는 `tailscale serve status --json`을 읽어 443·8443·10000 중 빈 곳을 쓰고, 다 차면 무엇이 쓰는지 보이고 고르게 한다.
- **F7 자동 허용.** `WEB_HOST`가 `0.0.0.0`(와일드카드)이면 이 기기 자신의 tailnet 주소(IP·MagicDNS 이름, 이 기기 Tailscale에서 읽음)를 허용 목록에 자동으로 더하고 Settings › 주소에 "자동으로 허용했어요"로 보인다.
- **F8 403 안내.** 주소가 허용되지 않으면 데스크톱 앱·웹 모두 꺼지지 않고 안내 화면("이 서버가 {host}를 허용하지 않아요 · 서버 맥에서 Settings › 주소의 다른 기기에서 열 주소에 넣어 주세요")을 보인다. 데스크톱 앱에는 다른 서버 고르기와 다시 시도가 있다.

## 구현 판단

- 빈 포트는 8443 → 10000 → 443 차례로 고른다. 443은 Serve 화면과 데스크톱 앱의 서버 찾기가 쓰는 자리라 마지막에 둔다.
- 이 서버의 webhook 경로만 연 포트가 이미 있으면 그 포트를 다시 쓴다. 다른 경로가 같이 있으면 Funnel이 포트 전체를 공개하므로 다시 쓰지 않는다.
- `serve status`를 읽지 못하면 8443 명령에 "실행 전에 비어 있는지 확인" 안내를 붙인다.
- `WEB_HOST=::1`은 그 주소에서만 받으므로 `127.0.0.1`로 바꾸지 않고 `[::1]`을 넘긴다.
- 자동 허용 주소는 15초 동안 기억한다. 허용되지 않은 Host가 오면 다시 읽고 판단한다. Tailscale을 읽지 못하면 마지막 주소를 지키고, 꺼졌으면 비운다.
- 403 안내는 스크립트 없는 정적 HTML이다. 막힌 Host에는 앱 번들과 데이터를 내주지 않는다.

## 완료 조건

- 시험: `serve status` 여러 경우(빈 포트, 다 참, 이상한 출력), `WEB_HOST` 경우별 명령과 안내, 와일드카드 바인드 때 자기 tailnet 주소 자동 허용, 403 안내 화면(웹·데스크톱).
- 스크린숏: Funnel 상자(포트 고름, 다 참), Settings › 주소 자동 허용, 403 안내.
