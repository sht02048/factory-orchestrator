# 0111 모바일 8: 앱에서 할당·다시 맡기기

## 목표

앱에서 티켓을 할당하고 Failed 런을 다시 맡긴다. 둘 다 확인 시트를 거친다(스펙 [0002](../spec/0002-mobile.md) M3).

## 범위

- 운영자가 열린 질문 9를 정한 뒤 범위를 채운다. 정하기 전에는 시작하지 않는다.
- 지금 서버 규칙: 끝나지 않은 런이 있는 티켓은 할당할 수 없다(`active-run`). Disconnected 런은 끝나지 않은 런이라 다시 맡길 수 없다.

## 시작할 때 운영자와 정할 것

- 할당할 티켓을 어디서 고를지, Queued 런을 다른 러너로 옮길지와 그 방법, 다시 맡길 때 이전 런의 러너·에이전트를 그대로 쓸지(스펙 0002 열린 질문 9).

## 완료 조건

- 열린 질문 9의 결정을 이 티켓에 적은 뒤 정한다.
