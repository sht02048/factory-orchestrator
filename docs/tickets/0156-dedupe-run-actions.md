# 0156 중복 요청 막기

## 목표

같은 동작을 두 번 눌러도 한 번만 처리한다(운영자 결정 F5, 2026-11-21).

## 배경

0147의 에이전트에게 보내기는 요청 ID로 같은 요청을 한 번만 처리한다. 워크트리 지우기, Human Check 답, 런 쓰기 동작에는 이 보호가 없어 더블클릭이나 다시 보내기로 같은 일이 두 번 일어날 수 있다.

## 할 일

1. 화면: 요청을 보내는 동안 버튼을 막는다.
2. 서버: 같은 요청 ID를 한 번만 처리한다(0147 방식).
3. 적용 대상: 워크트리 지우기, Human Check 답, 런 쓰기 동작(취소, 멈추기, 답하기, 이어서 맡기기).

## 완료 조건

- 시험: 동작마다 같은 요청 ID를 두 번 보내도 한 번만 처리하고 같은 결과를 돌려준다.
- 시험: 보내는 동안 버튼이 막힌다.
