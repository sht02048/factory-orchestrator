# 0150 PR 정보에 CI·충돌·뒤처짐 보이기

## 목표

PR을 읽을 때 CI 결과, 충돌, base보다 뒤처짐을 함께 읽어 Runs 행과 Run 상세 PR 구역에 작은 표시로 보인다. 런 결과는 바꾸지 않는다. 스펙 [0006](../spec/0006-agent-control.md) C7(운영자 결정 2026-11-21).

## 배경

0145부터 PR은 요약 결과 곁의 정보다. 지금 PR 정보는 상태(Open·Merged·Closed·못 읽음)와 CI 상태 하나뿐이라, 운영자가 PR이 왜 머지되지 않는지(CI 실패, 충돌, 뒤처짐) 보려면 GitHub로 가야 한다.

## 할 일

1. codehost-github: PR을 읽을 때 `statusCheckRollup`(검사 수와 실패한 검사 이름), `mergeable`(충돌), base보다 뒤처진 커밋 수를 함께 읽는다. 응답은 zod로 파싱한다.
2. 읽는 주기는 0144의 PR 다시 읽기를 따른다. 새로 주기를 만들지 않는다.
3. DB: 런의 PR 기록에 읽은 값과 읽은 때를 더한다.
4. Runs 행에 작은 표시(CI 실패, 충돌, "base보다 n커밋 뒤"), Run 상세 PR 구역에 줄로 보인다. 요약 결과와 To do는 바꾸지 않는다(스펙 0005 R1).
5. CI 다시 돌리기 버튼은 넣지 않는다.
6. MCP 런 읽기 출력에 같은 값을 보인다.

## 완료 조건

- 시험: 응답 파싱(성공·실패·대기·없음, 충돌, 뒤처짐), 저장, Runs 행·Run 상세 표시, 결과가 바뀌지 않음, MCP, 400px.
- 스크린숏: Runs 행의 표시, Run 상세 PR 구역.
- 화면 변경 있음. DB 변경 있음(one-way).
