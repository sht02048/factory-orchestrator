# 0059 Home을 Dashboard로 바꾸는 결정

## 목표

Home 개편(티켓 0060)에 앞서 화면 이름, 용어, 버튼 규칙을 ADR과 GLOSSARY에 먼저 고친다.

## 배경

UI 리뷰 후속(0050~0057) 뒤 운영자가 Home의 문제로 세 가지를 짚었다. 티켓 런과 러너 문제가 한 목록에 섞인다. 카드가 쓸데없이 길다. 오른쪽 위 개수 타일이 잘 안 보이고 위치가 이상하다. 시안 몇 차례 끝에 운영자가 고른 방향은 다음과 같다(2026-11-18).

- 화면 이름은 Home이 아니라 Dashboard다.
- 왼쪽에 사람이 할 일(To do)과 진행 중인 런(In progress), 오른쪽에 시스템 상태(Runners, Done today)를 둔다. 러너 문제는 To do에서 빼 오른쪽 Runners 카드로 옮긴다.
- "지금 일어나는 일" 흐름은 다른 구역과 겹쳐 뺀다. 그 자리에 오늘 끝난 런을 둔다.
- 질문은 행 안에 펼치지 않고, "답하기"를 누르면 뜨는 레이어에서 답한다. 선택지를 고른 뒤 "보내기"를 눌러야 보낸다.
- "손댈 일"은 쓰지 않는 말이라 To do로 바꾼다.

## 범위

- **ADR 0010 고치기**(새 ADR로 대체하거나 0010에 개정 절을 더한다. 어느 쪽인지는 저장소 ADR 관례를 따른다).
  - 3번(메뉴·화면 이름): Home → Dashboard.
  - 6번(버튼): 질문 선택지는 "모두 같은 보조 버튼"이 아니라 하나를 고르는 라디오 항목이다. 고른 뒤 "보내기"로 보낸다. 레이어(팝오버·대화상자) 안의 주 행동 하나는 파란 주 버튼을 쓸 수 있다.
  - "바뀌는 화면"의 Home 설명: 손댈 일 카드 + 흐름 → To do / In progress / Runners / Done today.
- **GLOSSARY 고치기**
  - "손댈 일" 항목을 **To do**로 바꾼다. 종류에서 Runner Issue를 뺀다(Runners 카드와 레일 Runners 아이콘 점에서만 보인다). _Avoid_에 "손댈 일"을 더한다.
  - Home을 가리키는 다른 항목의 낱말을 Dashboard로 바꾼다.
- 코드는 고치지 않는다(0060이 한다).

## 완료 조건

- ADR과 GLOSSARY에 위 결정이 들어 있고, 서로 어긋나는 문장(Home, 손댈 일, 선택지 보조 버튼)이 남지 않는다.
- 다른 문서(README, 티켓 README, DESIGN.md)에서 "손댈 일"·"Home 화면"을 가리키는 문장을 찾아 같이 고친다.
