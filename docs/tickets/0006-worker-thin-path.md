# worker 얇은 경로: 대기열에서 판정까지

## 목표

가짜 어댑터로 할당 → Queued → Running → Ended(판정)까지 한 번에 도는 worker 데몬 뼈대를 만든다. 이후 worker 티켓은 이 루프에 살을 붙인다.

## 범위

- 이 티켓은 `apps/worker`만 고친다.
- 폴링 루프: Queued 런을 FIFO로 꺼내 러너를 골라 시작하고(capacity 확인), Running 런을 폴링해 에이전트 종료를 감지하고, CodeHost로 PR을 찾아 core 판정 함수로 결과를 쓴다.
- 어댑터는 주입받는다. 이 티켓은 core의 가짜 어댑터로만 돈다.
- 재시작 안전: 상태는 DB에만 두고, 데몬이 어느 지점에서 죽었다 다시 떠도 같은 런을 두 번 시작하지 않고 이어서 폴링한다(ADR 0002·0005).
- 런은 db의 할당 진입점(0005)으로 만든다.

## 완료 조건

- 가짜 어댑터로 런 셋을 할당하면 capacity만큼 시작하고 나머지는 Queued로 남았다가 차례로 시작한다는 테스트가 통과한다.
- 가짜 PR 상태(병합됨, 열림, 닫힘, 없음)에 따라 런이 Merged / Human Check / Failed로 끝난다는 테스트가 통과한다.
- 런 시작 직후 데몬을 멈췄다 다시 띄워도 런이 하나만 시작된다는 테스트가 통과한다.
