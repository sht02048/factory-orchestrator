# 0060 Dashboard 화면 구현

## 목표

Home 화면을 0059에서 정한 Dashboard 구조로 바꾼다.

## 화면 구조

제목 "Dashboard"와 요약 한 줄 아래에 두 열을 둔다. 좁은 폭에서는 한 열로 쌓고, 쌓였을 때 오른쪽 열도 전체 폭을 쓴다(컨테이너 쿼리).

- **왼쪽 열**
  - **To do**: Question, Permission, Human Check, Failed, Disconnected 런. 러너 문제는 넣지 않는다.
  - **In progress**: Running과 Queued 런 전부. 머리에 "Running N · Queued N", 오른쪽에 Runs 링크.
- **오른쪽 열**(제목 없음, 카드 둘)
  - **Runners**: 문제 있는 러너마다 한 줄(이름은 Runners 링크, 까닭), 나머지는 "N대는 Online이에요" 한 줄.
  - **Done today**: 오늘 끝난 런 최근 5개(상태 점, 키, 제목, 끝난 시각). 머리에 "Merged N · Canceled N"과 "모두 보기"(Runs).
- 빼는 것: 개수 타일(오른쪽 위), "지금 일어나는 일" 흐름.

## 행

모든 구역의 행은 같은 구조다.

- 앞 묶음: 상태 알약 · 회색 키 · 제목. 제목은 Run 상세 링크다. 행 전체를 링크로 하지 않는다(행 안 버튼과 겹치지 않게).
- 뒤 묶음: 까닭이나 메타(시간, 러너) · 행동 버튼. 폭이 모자라면 뒤 묶음이 다음 줄로 내려간다. 제목이 먼저 사라지거나 행이 넘치지 않는다.
- 행동 버튼은 제목 링크와 다른 일을 할 때만 둔다: Question "답하기", Permission "거절하기", Human Check "PR 보기".

## 질문 레이어

- Question 행의 까닭 자리에는 질문 문장을, 오른쪽에는 "답하기"를 둔다.
- "답하기"를 누르면 그 아래에 레이어(팝오버, `packages/ui`의 팝업 스타일)를 띄운다. 레이어 안에는 알약·키·경과, 질문, 선택지(라디오), 마지막 항목 "직접 쓰기"가 있다. "직접 쓰기"를 고르면 그 아래에 글쓰기 칸이 열린다.
- 선택지를 눌러도 바로 보내지 않는다. 맨 아래 "보내기"(레이어 안의 주 버튼)를 눌러야 보낸다. 아무것도 고르지 않으면 "보내기"는 꺼져 있다. 직접 쓰기에서는 ⌘ Enter로도 보낸다.
- 선택지 문구는 길이 제한이 없다. 줄을 바꿔 다 보인다.
- 닫기: ×, Escape, 바깥 누르기. 닫히면 포커스를 "답하기"로 돌린다. 보내고 나면 레이어를 닫고 결과를 `role="status"`로 알린다.

## 문구

화면 문구는 메시지 파일(`apps/web/messages/ko/`)에 둔다. 이름(구역, 상태)은 영어 용어, 문장은 해요체다.

| 자리             | 문구                                                                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 화면 제목        | Dashboard                                                                                                                                              |
| 요약             | 처리할 일이 {todo}개, 확인할 러너가 {runners}대 있어요.                                                                                                |
| 구역             | To do / In progress / Runners / Done today                                                                                                             |
| In progress 링크 | Runs에서 보기                                                                                                                                          |
| Permission 까닭  | {command}를 실행해도 될지 묻고 있어요 · 허용은 러너에서 할 수 있어요                                                                                   |
| Permission 버튼  | 거절하기                                                                                                                                               |
| Human Check 까닭 | PR {pr}를 확인해주세요                                                                                                                                 |
| Failed 까닭      | Tickets에서 다시 할당할 수 있어요                                                                                                                      |
| Queued 까닭      | 빈 러너를 기다려요 / {runner}가 Offline이라 기다려요                                                                                                   |
| Runners 머리     | {count}대를 확인해주세요 · 모두 보기                                                                                                                   |
| Runners 행       | Offline · {duration}째 / GitHub 인증을 다시 해주세요 / {count}대는 Online이에요                                                                        |
| Done today 링크  | 모두 보기                                                                                                                                              |
| 질문 레이어      | 직접 쓰기 / 에이전트에게 보낼 답을 써주세요 / 답을 하나 골라주세요 / 보낸 답은 바로 에이전트에게 전해져요 / ⌘ Enter로도 보낼 수 있어요 / 보내기 / 닫기 |

조사(를/을, 가/이)는 끼워 넣는 값에 맞게 처리한다.

## 범위 밖

- 다른 화면의 레이아웃. 레일 메뉴의 이름과 아이콘을 Dashboard로 바꾸는 일은 범위 안이다.
- 질문 선택지 번호 단축키(1, 2 키).

## 완료 조건

- 러너 문제가 To do에 없고 Runners 카드에 있다는 시험.
- 선택지를 눌러도 보내지 않고 "보내기"를 눌러야 보낸다는 시험.
- 레이어를 닫으면 포커스가 "답하기"로 돌아온다는 브라우저 시험.
- 긴 선택지가 줄을 바꿔 다 보인다는 시험.
- 375px 폭에서 행이 넘치지 않는다는 브라우저 시험과 스크린숏(PR에 붙인다).
- 화면 전체에서 파란 주 버튼은 레이어 안의 "보내기" 하나뿐이라는 시험(기존 시험 고치기).
- 코드에 주석을 더하지 않는다(AGENTS.md).
