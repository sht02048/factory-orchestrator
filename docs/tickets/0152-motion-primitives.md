# 0152 움직임 토큰과 공용 동작(packages/ui)

## 목표

상태가 바뀐 곳을 운영자가 눈으로 따라갈 수 있게, 화면이 가져다 쓰는 움직임 토큰과 공용 동작을 `packages/ui`에 만든다. 화면 적용은 [0153](0153-apply-motion.md)이 한다.

## 운영자 결정(2026-11-21, 시안 "Ganger Motion" 승인)

- M1 원칙: 상태가 바뀔 때만 짧게 움직인다. 키보드·탭·필터·hover·로그 흐름·계속 도는 표시는 움직이지 않는다. transform·opacity만 움직이고 높이 펼치기는 `grid-template-rows`로 한다. 나가기는 들어오기보다 20~30% 짧다. 짝(바탕+대화상자)은 같은 시간이다. 열고 닫기는 transition으로 도중에 되돌리고, 한 번 도는 들어오기만 keyframes다.
- M2 값: 들어오기·나가기 곡선 `cubic-bezier(0.23,1,0.32,1)`, 화면 안 이동 곡선 `cubic-bezier(0.65,0,0.35,1)`. To do 행 들어오기 220ms(펼침 + 6px 내려앉기), 빠지기 160ms(접힘 + 흐려짐). 도착 비추기 1200ms(강조색 18% → 면색). 상태 알약 색 150ms + 1.06 한 번 커지기 180ms. Runs 행 자리 바꾸기 240ms. 타임라인 새 줄 200ms(6px 떠오름). 대화상자 열기 180ms(0.96→1)·닫기 140ms(0.98, 4px), 바탕 같은 시간. Sheet 열기 260ms `cubic-bezier(0.32,0.72,0,1)`·닫기 180ms 같은 쪽으로. Dashboard 카드 칸 옮기기 300ms, 남은 카드 같은 시간, 도착 비추기.
- M3: 한꺼번에 3장(행)보다 많이 바뀌면 미끄러지지 않고 흐려지며 바뀐다. 옮겨 갈 자리가 화면 밖이거나 좁은 폭으로 칸이 세로로 쌓이면 흐려지며 바뀐다.
- M4: `prefers-reduced-motion`에서는 이동·커지기를 빼고 150ms 이하 흐려지기만 남긴다. 기본 상태가 애니메이션 없이는 안 보이는 일이 없게 한다.
- M5: 첫 화면 렌더는 움직이지 않는다. SSE·사용자 행동으로 바뀐 것만 움직인다.

## 할 일

1. 토큰: 이동 곡선과 위 시간들을 `motion`에 뜻 이름으로 더하고 DESIGN.md 표를 고친다.
2. 공용 동작: 목록 항목 들어오기·빠지기(빠짐 뒤 제거 시점 알림), 도착 비추기, 자리 바꾸기(View Transitions API, 안 되면 FLIP, 둘 다 안 되면 즉시), 상태 알약 바뀜 표시, 대화상자·Sheet 닫기 움직임. M3·M4 판단을 공용 동작 안에 둔다. 새 애니메이션 라이브러리를 더하지 않는다.
3. `/ds`에 각 동작을 눌러 볼 수 있는 견본을 더하고 DESIGN.md에 언제 쓰는지 적는다.

## 완료 조건

- 시험: reduced-motion 경로, 한꺼번에 많이 바뀜 판단, 빠짐 뒤 제거, 대화상자 닫기 중 다시 열기(되돌림), 첫 렌더 무움직임.
- 브라우저 시험을 CPU 부하에서 5회 돌려 모두 통과한다(부하 프로세스 최대 4개).
- 화면(`apps/web`의 Dashboard·To do·Runs·타임라인)은 바꾸지 않는다. `/ds`만 바꾼다.
- DB 변경 없음. two-way.
