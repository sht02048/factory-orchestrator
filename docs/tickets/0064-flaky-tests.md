# 0064 남은 흔들리는 시험 두 가지

## 목표

CI `check`가 코드와 상관없이 실패하는 일을 없앤다.

## 배경

0061이 e2e 화면 준비 시간 초과와 토스트 문구 중복을 고쳤다. 그 뒤에도 두 가지가 남았다(2026-11-18).

- `apps/cli/src/start.test.ts` "한쪽이 먼저 끝나면 다른 쪽도 멈추고 이유를 알린다"가 CI에서 두 번 실패했다(PR #80, PR #91). 오류는 `StartError: stopped before web responded: worker exited with code 3`이다. 일부러 죽는 가짜 worker가 web이 응답하기 전에 끝나는 타이밍 경쟁으로 보이지만 확정하지 않았다. 다시 돌리면 통과했다.
- `demo/src/dev.test.ts:80`이 토스트를 페이지 전체에서 찾는다. UI SDK가 같은 문구를 스크린 리더 알림 영역에도 넣어서, 0061이 고친 것과 같은 중복으로 실패할 수 있다.

## 범위

- start.test의 실패를 재현해 원인을 증거로 확정하고 고친다. 시험이 확인하는 동작(한쪽이 끝나면 다른 쪽도 멈추고 이유를 알린다)은 바꾸지 않는다. 원인이 cli 코드의 경쟁이면 코드를 고친다.
- dev.test의 토스트 대기를 0061과 같이 토스트 영역 안으로 좁힌다.

## 완료 조건

- start.test를 CI와 비슷한 부하에서 반복해 모두 통과한 기록.
- 같은 head에서 CI `check`가 두 번 통과한다.
